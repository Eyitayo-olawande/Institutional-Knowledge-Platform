# packages/ui

Design system shared by the customer application and the admin console. Phone first and light pages. All screen text comes from translation files.

Epic: E1 (design system base).

Base in place: design tokens (colour, spacing, type, radius, a 44px phone touch target) exported as values and as CSS variables, and a Button that takes its label from the caller. Values are neutral placeholders until the designer sets the visual direction in weeks 1 and 2.
