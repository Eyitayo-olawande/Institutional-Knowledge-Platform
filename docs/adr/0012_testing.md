# ADR 0012: Testing

* **Status:** Proposed
* **Date:** 14 October 2026
* **Drafted by:** Claude Code
* **Approver:** Technical lead (not yet named)
* **Source:** Development Roadmap v1, section 4; Product Architecture v1

## Context

Because Claude Code writes most of the code, tests are the main safety net. The roadmap defines unit, integration, tenant isolation, permission, migration, end to end, accessibility and performance tests.

## Decision

Use Vitest for unit and integration tests, and Playwright for end to end tests.

## Why

Fast, well known, runs in the pipeline.

## Consequences

* Integration tests run against a real PostgreSQL database.
* Test data is a fictional insurer generated by script.

## Open questions

* Accessibility check tool not named in the source documents.
