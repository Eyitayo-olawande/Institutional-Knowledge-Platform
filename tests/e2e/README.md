# tests/e2e

End to end and tenant isolation tests.

* End to end: main journeys in a browser (new hire path, test and certificate, SOP change and confirmation, leaver handover). Runs on every merge to main.
* Tenant isolation: two test tenants; every endpoint tried with the wrong tenant's identifiers must fail. Runs on every change.

Test data is a fictional insurer generated by script, never real SUNU personal data.

Proposed in the roadmap: Playwright for end to end tests. Not confirmed until the decision record is approved.
